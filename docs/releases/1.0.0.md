# PhoneAgent 1.0.0

发布日期：2026-11-05。Android `versionCode 10`。

以 0.4.0 已验收的月薪喵气泡界面作为 1.0.0 基线，沿用原有安装签名，可直接覆盖升级，保留模型配置和会话记录。

## 本版范围

- 手机上的后台 Linux 运行环境和 Claude Code，通过兼容 Anthropic API 的外部模型执行手机操作。
- 原有月薪喵悬浮入口与状态动画，顶部集中新任务、任务记录和连接设置。
- 用户和助手左右气泡，执行过程折叠、Markdown 结果、复制与真实会话续聊。
- 最近任务左滑显示删除按钮，手动停止及出错后重置；App 不设置任务轮数或总时长上限。
- 新增不调用模型的自动 UI 回归入口，单独记录每项耗时和数据保留结果。

1.0.0 仍为当前个人手机使用的侧载构建；语音输入尚未加入。此版本号不代表新增模型能力或改变此前的手机控制范围。

## 验证

默认自动 UI 回归实测 126.654 秒通过，59 项主机测试通过。升级前后会话记录和加密配置的文件哈希一致。详见 [1.0.0 实机记录](../validation/2026-11-05-huawei-ctr-al00-v1.0.0.md) 和 [快速回归入口](../testing.md)。

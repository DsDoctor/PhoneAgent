# PhoneAgent 1.1.0

Android `versionCode 11`。沿用安装签名覆盖升级，保留手机上的模型配置、任务会话、Claude 原生记忆和脚本。

- Claude 原生反问显示为单选、多选和自由回答卡片；用户明确提交后继续原任务，悬浮猫和通知显示等待状态。
- 运行中点悬浮猫，先暂停手机动作，再进入当前任务补充要求；拖动悬浮猫不暂停。输入补充或直接继续后，重新读取手机界面。
- 暂停和待回答记录持久化，进程消失或 App 重启后保持等待；只有用户明确继续才通过原会话恢复。结束任务与重置展示仍是独立操作。
- 开放原生 Read、Write、Edit、Glob、Grep，允许把记忆和文件保存到手机。沿用 Claude Code 的原生记忆机制；本版不提供云同步、备份界面或 Bash。
- 手机桥接的动作代次使暂停前排队的点击、手势和复合脚本后续步骤失效；已派发的手势结束后才打开输入界面。

69 项本机测试通过；隔离的 Claude/App 交互回归通过，用时 110.11 秒，不调用外部模型；默认 UI 快检 126.765 秒通过。

验证记录见 [1.1.0 实机记录](../validation/2026-11-05-huawei-ctr-al00-v1.1.0.md)。

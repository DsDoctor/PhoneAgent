# PhoneAgent 1.1.1

Android `versionCode 12`。沿用安装签名覆盖升级，保留手机上的模型配置、任务会话、Claude 原生记忆和脚本。

- 暂停及运行中的结束按钮统一为单行“结束”，结束后仍可用同一位置“重置”。
- 原生模型重试事件显示 HTTP 状态、次数与等待时间，月薪喵和通知提示重试；手机工具及文件工具的当前阶段也会显示。脚本已完成验证、仍等待模型整理结果时给出明确说明。
- 整次任务累计各段 Claude Code 执行轮次，暂停前的结果也计入；单独统计回复、服务重试、工具调用和手机操作请求。旧版末段计数明确标注未累计，不推算缺失数据。
- 手机控制分别判断系统开关、授权项与实际服务连接，返回 App 或服务延迟连接后自动刷新。模型已配好但无障碍未连接时，不再笼统显示“待配置”。

没有新增任务轮数或总时长上限。无障碍授权仍由 Android 管理，普通 App 无法静默重新授权。

70 项主机测试通过；本机固定响应的实机交互回归通过，用时 168.14 秒，未调用外部模型，真实配置、历史和 Linux HOME 文件摘要保持一致。

验证结果见 [1.1.1 实机记录](../validation/2026-11-05-huawei-ctr-al00-v1.1.1.md)。

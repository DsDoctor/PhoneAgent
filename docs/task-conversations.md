# 任务记录与继续对话

0.4.0 起使用月薪喵的暖色对话界面，默认打开当前任务。顶部集中显示宠物状态、左侧“新任务”、右侧“任务记录”和“连接与设置”，不随对话滚走；底部固定输入和执行/继续对话、结束/重置按钮。

点击“任务记录”进入最近 20 个会话的列表，按最近活动时间排序。新任务创建独立会话；点开历史记录后，在输入框追问会添加下一轮对话。每轮按时间显示右侧用户指令气泡和左侧月薪喵回复气泡。回复中保留折叠的执行过程、Markdown 最终结果和真实结束状态。

## 真正恢复原会话

App 保存 Claude Code 在 init/result 中返回的会话 UUID，继续时显式传入 `--resume <session_id>`，沿用该会话的实际上下文。每次启动仍创建新的手机工具连接，模型须重新观察手机当前界面。没有有效会话 ID 或手机内原始会话文件已丢失时，界面说明无法继续；不会把历史文字拼进新任务并当作恢复。

最近记录的数量是界面存储策略，不是执行预算。整次任务仍没有 App 设置的轮数或总时长截止，手动停止和局部工具/网络超时保持有效。停止、报错和完成后，重置只恢复待命，不删除历史记录。

## 过程与最终结果

`process` 保存可显示的执行阶段和助手中间说明；`result` 保存 CLI 成功结束事件中的最终结果。没有最终结果的回合会明确说明，过程文本不会冒充最终答复。终态原因和可取得的轮数/退出码独立显示。

Markdown 使用原生 Android 组件显示，包括标题、强调、列表、引用、代码和表格；表格可横向滚动。复制结果保留原始 Markdown。链接仅允许通过用户点击打开 HTTP/HTTPS 地址；不执行原始 HTML 或 JavaScript，不自动加载远程图片。

## 执行统计与重试提示（1.1.1）

“累计执行轮次”是同一次 App 任务内各段 Claude Code query 的原生 `num_turns` 之和，包含暂停前被中断的段；不是 API 请求次数，也不是工具数量。原生反问的回答仍属于当前 query，暂停后提交补充会开始新 query。每段最终事件在处理暂停分支之前结算，恢复任务时继续已有账本。

另外分别显示模型回复数（按原生消息 ID 去重）、服务重试数（按 `system/api_retry` 去重）、工具调用数和进入手机桥接的操作请求数。手机请求数不表示成功动作数；一个复合工具可以产生多个手机请求。还有未返回结果的 query 时显示“尚未结算”，不猜测其最终轮数。

旧版记录只保存了最后一段轮数，显示为“旧版末段轮次（未累计）”，不改写原始历史、不把它冒充整次任务的总数。统计账本只保存摘要 ID，最多 2048 个去重身份；超过后标记统计不完整，不限制任务执行。

服务返回原生重试事件时，月薪喵显示“重试”，过程显示安全的 HTTP 状态、重试次数与倒计时。界面每秒刷新等待时间，每隔 30 秒留一条等待记录；这些刷新不发起模型请求。脚本已验证成功时先显示脚本验证结果，继续等待模型整理最终答复，不直接把局部脚本成功当作整个任务完成。

## 存储与升级

会话记录位于 App 私有目录 `files/task-history.json`，使用 AtomicFile 更新。每个输出字段保留尾部最多 24,000 个 UTF-16 代码单元，不保存配置对象、原始模型思考或完整工具请求参数；认证信息继续脱敏。`files/last-task.json` 保持上一版本的终态恢复兼容。

升级时自动保留上一版最近任务的原始记录。旧格式没有记录原始指令与 session ID，因此自动迁移的旧记录仅供查看，直到根据实际 Claude 会话日志关联。现有设备的真实历史可由开发维护时在私有目录导入；测试输出不应混入用户会话。

语音输入本版尚未实现，不请求录音权限。

## 删除不再需要的记录

在最近任务中向左滑动一项，右侧会出现“删除”；点按钮才删除。向右滑动或点已展开的卡片会收起按钮，竖向滚动不会触发删除。一次只展开一项。读屏辅助可使用“显示删除按钮”操作。

正在执行的会话须先停止才能删除；其他历史仍可删除。删除后重启不会重新出现；其他会话、模型连接配置和已保存脚本保留。删除清理的是 App 的会话展示记录及关联上一任务记录，Linux 内的原始 Claude 会话文件不会随之清理。
